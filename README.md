# HealthCare Connect

A React and Vite prototype for a doctor appointment booking platform. The interface covers public doctor discovery, patient sign-in and booking, appointment views, and a doctor onboarding and practice workspace.

## Run locally

Requirements: Node.js and npm.

```sh
npm install
npm run dev
```

Available scripts:

- `npm run dev` — start the local development server
- `npm run build` — create a production build
- `npm run preview` — preview the production build
- `npm run lint` — run ESLint

## Prototype limitations

This project is a frontend demo. Its service layer uses mock data and browser storage; authentication, OTP delivery, appointment persistence, payment, document handling, verification and notifications are not connected to production services. The payment screen is simulated and does not process real payments.
